# ⚡ Sako Desk — Удаленный доступ к ПК и управление с телефона без ограничений (аналог AnyDesk / RustDesk)

Нативное высокопроизводительное приложение для Windows (`.NET 9` + `Win32 API`) со встроенным Relay-сервером и веб-сервером для полного управления компьютером с телефона (**Android / iPhone**) через Wi-Fi или 4G/5G интернет.

---

## 📱 Управление ПК с телефона без ограничений (Wi-Fi + 4G/5G Интернет)

В **Sako Desk** встроен собственный мобильный сервер (порт `9880`) и глобальный интернет-туннель:
1. Нажмите в программе зелёную кнопку **«📱 Подключить Телефон (QR / Ссылка)»**.
2. Выберите способ подключения:
   - **Через домашний Wi-Fi** (`http://192.168.x.x:9880`) — мгновенный отклик и до 30 FPS без задержек.
   - **Через 4G / 5G / Мобильный интернет из любой точки мира** — нажмите кнопку **«🌍 Включить 4G/5G»**, и программа автоматически создаст защищённую публичную `https://...` ссылку. Откройте её на телефоне где угодно и введите ваш пароль.
3. **Возможности мобильного пульта Sako Desk Pro**:
   - **👆 Касание и 🖱 Тачпад**: прямое нажатие пальцем по экрану или режим тачпада ноутбука с плавным курсором.
   - **✊ Зажать (Drag & Drop)**: позволяет зажать левую кнопку мыши и перетаскивать окна, выделять текст или перемещать файлы пальцем.
   - **⚡ Панель «Система»**: горячие клавиши `Диспетчер задач (Ctrl+Shift+Esc)`, `Alt+F4`, `Alt+Tab`, `Свернуть все окна (Win+D)`, `Пуск`, `Ctrl+C / Ctrl+V`.
   - **💻 Панель «Терминал»**: выполнение любых команд `PowerShell / CMD` на компьютере прямо с телефона с выводом результата.
   - **📁 Отправка файлов с телефона на ПК**: кнопка `📁 Файл на ПК` мгновенно передаёт любые фото или документы из телефона на рабочий стол компьютера (папка `SakoDesk_Received`).

---

## 💻 Управление ПК ⟷ ПК
- **9-значный ID и пароль** (в стиле AnyDesk / RustDesk).
- **Автопоиск компьютеров в локальной сети** (UDP Discovery на порту `9869`).
- **Прямое подключение** (порт `9870`) и **Relay-сервер** (порт `9871`) для соединения компьютеров через интернет за NAT.
- **Передача файлов, чат и скриншоты** прямо во время сессии.

---

## 🚀 Сборка и запуск
- Быстрый запуск: откройте **`Запустить Sako Desk.bat`** (или `bin\SakoDesk.exe`).
- Сборка из исходников:
  ```powershell
  dotnet publish SakoDesk.csproj -c Release -o bin
  ```
